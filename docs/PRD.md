# Haitun Post Studio 产品需求文档

> 状态：当前实现基线
> 更新日期：2026-07-21
> 适用版本：0.1.x

## 1. 产品概述

Haitun Post Studio 是面向企业创意与后期团队的项目制 AIGC 协同创作平台。它把图像、视频、音乐、配音、素材管理和生成任务集中在同一工作台，帮助团队快速探索创意并沉淀可复用的媒体资产。

当前版本的核心目标是“生成与协作”，不是自动完成从脚本到成片的整条制片流水线。

## 2. 目标用户

| 角色 | 核心需求 |
| --- | --- |
| 设计师 / 创意 | 快速生成、编辑和比较视觉方案 |
| 视频创作者 | 生成短视频片段并复用首帧、尾帧和参考素材 |
| 运营 / 文案 | 为宣传内容制作图片、视频、音乐和旁白素材 |
| 项目负责人 | 组织成员、管理共享素材、查看任务和用量 |
| 平台管理员 | 查看全平台项目与使用统计，处理异常任务 |

## 3. 产品原则

- **项目制沉淀**：生成结果、上传素材、评论与任务都归属于项目。
- **作品优先**：媒体预览与创作结果优先于技术参数。
- **异步生成**：所有长耗时模型调用使用后台任务，前端轮询状态。
- **过程可溯源**：记录模型、提示词、参数和上游素材引用。
- **本地与云端同代码**：认证、数据目录和外部能力差异只由环境变量控制。
- **安全协作**：私有项目仅成员可见；组织内公开项目允许已登录用户只读浏览。

## 4. 当前功能范围

平台当前由六部分组成：项目空间、图像创作、视频创作、音乐与配音、素材库、任务中心。

### 4.1 项目空间

| 能力 | 说明 |
| --- | --- |
| 新建项目 | 设置项目名称、描述与可见性 |
| 项目信息 | 项目成员可修改名称与描述 |
| 私有项目 | 仅成员与管理员可见 |
| 组织内公开 | 所有已登录用户可见，非成员只读 |
| 添加成员 | 本地模式使用已注册邮箱；CAS 模式使用 LDAP 账号 |
| 在线状态 | 显示项目成员近期在线状态 |
| 管理员视角 | 管理员可以查看全平台项目与用量 |

### 4.2 图像创作

支持文生图与参考图生图。用户选择模型、尺寸、清晰度和提示词后提交后台任务，完成结果自动进入项目素材库。

图像创作包含以下辅助能力：

- 通过上传或从素材库选择参考图。
- 在提示词中使用 @ 引用项目素材。
- 对支持的模型使用交互式局部编辑区域。
- 从历史任务复用参数、再次生成。
- 使用“角色设定 / 场景设定 / 风格设定”预设生成结构化设定图。
- 设定图以素材标签保存，不形成独立角色库。

### 4.3 视频创作

根据所选模型能力提供以下模式：

| 模式 | 说明 |
| --- | --- |
| 文生视频 | 仅使用提示词生成视频 |
| 首帧参考 | 使用一张图片确定起始画面 |
| 首尾帧 | 同时指定开始与结束画面 |
| 全能参考 | 混合引用图片、视频和音频 |
| 视频延长 | 对现有视频向前补拍或向后续写 |

用户可以设置时长、比例、分辨率、是否生成声音等模型支持的参数。生成任务在后台执行；离开页面不影响任务继续运行。

当参考视频超过模型限制时，系统会打开裁剪对话框并把裁剪结果作为新素材保存。该能力不是独立剪辑工作台。

### 4.4 音乐与配音

#### 音乐

- 灵感生成歌曲。
- 输入歌词生成歌曲。
- 生成纯音乐 BGM。
- 配置模型支持的时长、曲风、情绪与音色。
- 生成结果自动进入素材库，可在波形视图中试听与截取片段。

#### 配音

- 使用预置音色进行语音合成。
- 部分音色支持语速和情感控制。
- 实验性 Qwen3-TTS 声音克隆允许上传参考音频；公共创空间在界面中明确标记为实验性共享服务，
  并显示健康状态、本站排队量，管理员配置自建实例后可在两者之间切换。
- 声音克隆必须提示授权与隐私风险，失败不能影响常规配音。

### 4.5 素材库

素材库统一管理项目中的图片、视频和音频。

| 能力 | 说明 |
| --- | --- |
| 自动归档 | 生成完成后自动保存产物 |
| 手动上传 | 支持拖拽和多文件上传 |
| 搜索筛选 | 按提示词、文件名、创建人和设定标签查找 |
| 详情与溯源 | 展示模型、提示词、参数、创建人和上游引用 |
| 审核状态 | 标记采用或废弃 |
| 评论 | 项目成员围绕素材讨论 |
| 视频截图 | 从视频当前帧生成新的图片素材 |
| 音频截取 | 在波形中选择片段并另存为素材 |
| 视频延长入口 | 从视频素材直接进入视频延长模式 |
| 下载与删除 | 按权限下载或删除素材 |

### 4.6 任务中心

任务中心汇总项目内所有生成与处理任务。

- 展示排队、运行中、成功、失败和已取消状态。
- 按任务类型与创建人筛选。
- 展示模型、输入参数、错误原因和关联产物。
- 允许取消仍可取消的任务。
- 允许重试瞬时失败任务；内容安全或参数被明确拒绝时必须先复用并修改输入，供应商可能已受理的重试需确认重复费用风险。
- 服务重启时识别被中断的本地任务，避免一直显示运行中。
- 管理员可查看按项目、成员和时间范围汇总的使用统计，包括按模型成功率、精确计时覆盖率、排队与执行 P50/P95、失败类型、成本，以及按成功结果 cohort 去重的下载率、复用率和再次生成率；缺少完整起止时间的历史任务不混入耗时分位数。

## 5. 认证与权限

### 5.1 本地模式

- `AUTH_MODE` 未设置或为 `local`。
- 使用邮箱和密码登录。
- 首位注册用户自动成为管理员。
- 后续注册需要邀请码。
- 添加项目成员时输入已注册邮箱。

### 5.2 CAS 模式

- `AUTH_MODE=cas`。
- 使用部署方配置的 CAS / LDAP 一键登录，不显示注册入口。
- 首次登录自动创建用户档案。
- 添加项目成员时输入 LDAP 账号；未登录用户可以预建档。

### 5.3 权限角色

| 角色 | 权限 |
| --- | --- |
| 非成员浏览者 | 只读查看公开项目与素材 |
| 项目成员 | 创作、上传、评论、评审和查看任务 |
| 项目创建者 | 成员权限 + 管理成员与项目可见性 |
| 管理员 | 查看全部项目、统计与管理范围内的资源 |

## 6. 异步任务与外部服务

- 所有可能超过约 10 秒的模型或外部服务请求必须创建后台任务。
- 浏览器只负责提交任务和轮询状态，不能同步等待大模型完成。
- 当部署域名无法被外部服务访问时，素材必须通过 Supabase `coze-bridge` 中转。
- 未配置可选能力时，相关功能应清晰失败或隐藏，不影响基础图像与视频流程。
- 企业微信 Webhook 未配置时静默跳过通知。

## 7. 数据与备份

- 本地默认使用 `./data`。
- 部署环境通过 `DATA_DIR` 指定持久化目录。
- 不同部署环境的数据互相独立，不自动同步。
- SQLite schema 变更必须使用兼容真实存量数据的迁移。
- 服务器每日备份 SQLite 快照和新增媒体到 Supabase Storage 私有桶 `haitun-backup`；数据库与媒体均写入 SHA-256 校验清单，删除媒体额外保留 30 天并通过墓碑安全清理。所有远端备份写入同时要求生产环境门禁 `BACKUP_REMOTE_WRITE_ENABLED=1`，手动执行还要求显式确认参数；本地与 E2E 即使持有 Supabase 凭据也不能写备份桶。远端清理使用幂等批量删除；恢复演练不覆盖运行中的数据目录。
- 备份目标为 RPO 24 小时、RTO 4 小时；单机 SQLite 在主库 1 GiB、任务 50 万行或磁盘使用率 70% 时进入扩容预警，不通过无限增加 worker 规避单写者与本地磁盘边界。

## 8. 非功能要求

| 维度 | 要求 |
| --- | --- |
| 性能 | Three.js 仅用于入口氛围；DPR 有上限，离屏暂停，移动端可降级 |
| 可访问性 | 支持键盘、可见焦点、语义标签和减少动态效果 |
| 可靠性 | 长任务不依赖单次 HTTP 连接；失败任务可定位和重试 |
| 安全 | 密钥只存服务端；项目接口必须校验登录与项目权限 |
| 响应式 | 项目入口、登录页和工作台在手机与桌面可用 |
| 可观测性 | 管理员能查看任务量、失败量与成员使用情况 |

## 9. 当前明确不包含

以下能力曾出现在旧文档或历史界面中，但当前版本已经移除，不应在对外说明中当作现有功能：

- 自动分镜流水线。
- 独立角色库。
- 文案 / 文本生成标签页。
- 独立的云端剪辑工具页。
- 批量镜头生成、一键成片与 SRT 导出。
- 独立时间线编辑器。

已有的角色 / 场景 / 风格“设定图”仍属于图像创作预设；参考视频裁剪仍属于视频生成前置处理。两者不代表恢复了角色库或剪辑工作台。

## 10. 技术架构

| 层级 | 实现 |
| --- | --- |
| 前端 | Next.js App Router、React、TypeScript、Tailwind CSS、Radix UI、Motion、Three.js |
| 服务端 | Next.js Route Handlers |
| 数据 | Drizzle ORM + SQLite |
| 任务 | SQLite 持久化任务 + 后台 worker / 轮询 |
| 模型 | 火山方舟 Seedream / Seedance |
| 音频 | Coze 音乐与 TTS、ModelScope Qwen3-TTS |
| 认证 | Auth.js + 本地凭证 / 可选 CAS |
| 媒体 | 本地文件系统 + Supabase 外部服务桥接 |
| 部署 | Node.js 或容器平台，持久化目录由环境变量配置 |
